## 📊 SEO & Web Analytics SQL Project
This project demonstrates how SQL can be used to analyze **website traffic, user engagement, and conversion behavior** using a structured dataset inspired by real-world web analytics tools such as Google Analytics.
The project is fully compatible with **MySQL Workbench** and focuses on deriving meaningful business insights using SQL queries.

### 🔍 Key Analytics Covered
- Daily Active Users (DAU)
- Bounce Rate
- Average Session Duration
- Top Landing Pages
- Pages per Session
- Users by Country
- Device Type Usage
- Long Sessions (> 5 minutes)
- Traffic Trends (Sessions per Day)
- Conversion Funnel (Products → Checkout)
